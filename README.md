# Glicko-2 Ranking

A small Java implementation of the Glicko-2 rating system.

Glicko-2 is a skill rating algorithm by Mark Glickman. It improves on Elo by tracking rating deviation and volatility. The algorithm is public domain; the reference paper is available here: [glicko2.pdf](http://www.glicko.net/glicko/glicko2.pdf), [repo copy](glicko2.pdf).

This project follows that specification and is intended for use in ranking systems (for example game servers).
